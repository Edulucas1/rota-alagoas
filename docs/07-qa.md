# 7. QA — Plano de Testes, Casos de Teste, Bugs e Rastreabilidade

## 7.1 Plano de testes

| Item | Definição |
|---|---|
| **Objetivo** | Garantir que o Rota Alagoas atende aos 8 requisitos funcionais e 3 não funcionais, com atenção especial ao recurso de IA e ao plano B. |
| **Escopo** | Cadastro/login, CRUD de pontos e eventos, listagens e filtros, avaliações, geração e gestão de roteiros, segurança básica e layout no celular. |
| **Fora do escopo** | Carga/estresse, testes em navegadores antigos, qualidade "turística" das sugestões da IA (avaliação subjetiva). |
| **Tipos de teste** | Funcional manual (caixa-preta), testes automatizados de unidade (`tests/testes_unitarios.php` — 17 testes), testes de segurança básicos (acesso, CSRF, chave da API), teste de responsividade. |
| **Ambiente** | Windows + XAMPP (Apache, PHP 8.2, MariaDB), Chrome/Edge. Ambiente de desenvolvimento: PHP 8.3 + MariaDB. |
| **Dados** | `database/rota_alagoas.sql` (25 pontos, 8 eventos fictícios com datas relativas, 12 avaliações). Contas: `ana@rota.al` (turista), `guia@rota.al`, `guia2@rota.al` (guias), `org@rota.al` (organizador). Senha `123456`. |
| **Critério de entrada** | Banco importado, `config/config.php` criado, sistema abrindo em `http://localhost/rota-alagoas`. |
| **Critério de saída** | 100% dos casos de prioridade Alta passando e nenhum bug Crítico/Alto aberto. |
| **Responsável** | José Wellington (QA), com apoio de toda a equipe. |
| **Cronograma** | Sexta, 23/10, antes da apresentação. |

### Como rodar os testes automatizados

```bash
# na pasta do projeto
php tests/testes_unitarios.php
# Windows/XAMPP
C:\xampp\php\php.exe tests\testes_unitarios.php
```

Resultado esperado: `Resultado: 17 passou, 0 falhou.`
